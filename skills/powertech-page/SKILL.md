# Powertech page work

Use this skill for page, copy, metadata, internal link, or route work in the Powertech Performance V4 repository.

1. Read `AGENTS.md` and, before SEO or content changes, `seo/SEO-RULES.md`. Check the relevant rows in `seo/seo-map.csv` and `seo/keyword-map.csv`; consult `seo/data-analysis.md` when interpreting metrics. Confirm offers against `seo/business-policy.json` and the current site. Do not infer services from old exports.
2. Inspect one closely related live page for the design, shared navigation, footer, form integration, and consent behavior. Reuse the existing assets and conventions where suitable. Keep existing legal, tracking, form, Ads, and GTM behavior unless the user specifically asks to change it.
3. Implement the requested page and only the necessary navigation, route, sitemap, and SEO records. Do not delete, rename, merge, or redirect an existing URL without explicit authorization. Keep claims, prices, contact details, and FAQs grounded in confirmed information.
4. Check the changed page in a browser at desktop and narrow width when layout matters. Use the focused checks in `$powertech-release` for completion.

Favor a single inspection of each source and targeted follow-up checks. Expand testing only when a concrete risk remains.
